Direct Print — Thermal Label & Receipt Printer via QZ Tray

Print labels & receipts directly from your browser to any thermal printer.
Zebra, TSC, Epson, Honeywell, Star — no PDF, no print dialog. Just click & print.

Key Features

QZ Tray Integration

Direct browser-to-printer communication via WebSocket. Print from any device to local USB printers without server access.

Label Template Designer

Create reusable label templates with drag-and-drop elements: text, barcodes, QR codes, lines, boxes, and raw ZPL.

Barcode Support

Code 128, Code 39, EAN-13, UPC-A, QR Code, DataMatrix — all major barcode formats supported.

Multi-Platform

Windows (USB via QZ Tray), Linux (CUPS), Mac (CUPS), and Network printers (TCP/IP port 9100).

Label Preview

See a rendered preview of your label before printing. Uses Labelary API for accurate ZPL rendering.

Print History

Complete audit trail of every print job with timestamps, user, printer, label count, and status tracking.

How It Works

1
Configure Printer — Add your printer in Direct Print → Printers. Select the language (ZPL, TSPL, ESC/POS, etc.) and enter the device name.
2
Design Label — Create a label template with text, barcodes, QR codes. Map fields from any Odoo model.
3
Select & Print — Select records (products, lots, etc.) → Click "Print Labels" → Labels print instantly.

Requirements

For Windows/Mac users (QZ Tray method):

  • Install QZ Tray on each user's PC (free)
  • Printer connected via USB and visible in OS printer list

For Linux (CUPS method):

  • CUPS installed and printer configured
